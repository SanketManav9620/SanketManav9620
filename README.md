### 2️⃣ Outskill Mailer — Email Queue & Slack Dispatcher
> A full-stack email scheduling platform with staggered batch sending, rate limiting, crash-safe workers and Slack alerts.

- ⏱️ BullMQ + Redis delayed jobs with no lost or duplicate sends after restarts
- 🚦 Atomic Redis rate limiting (100 emails/hour/sender)
- 🔎 Elasticsearch-powered email search
- 🔐 Google login (NextAuth) and Slack OAuth v2 integration
- 🐳 Docker Compose for PostgreSQL, Redis and Elasticsearch
- 🧰 **Stack:** Next.js 14 · Express · TypeScript · Prisma · PostgreSQL · BullMQ

[🔗 Live Demo](https://outskill-app-frontend.vercel.app) &nbsp;|&nbsp; [📂 Source Code](https://github.com/SanketManav9620/Outskill-app)

### 3️⃣ Reel Food — Short-Video Food Discovery Platform
> A TikTok / Reels-style vertical video feed connecting food lovers with local restaurants, plus a partner dashboard.

- 📱 Smooth vertical video feed with likes, saves and comments
- 🏪 Restaurant store profiles with video menu catalogues
- 🔐 JWT in HTTP-only cookies with Bcrypt password hashing
- ☁️ Video uploads through ImageKit CDN
- 🧰 **Stack:** React 19 · Vite · Node.js · Express 5 · MongoDB

[📂 Source Code](https://github.com/SanketManav9620/Reel-style-foodorderingApp)

### 4️⃣ Yes Bank Stock Price Prediction — ML Regression
> End-to-end analysis of 185 months of Yes Bank stock data to predict the closing price.

- 📈 EDA with trend plots, boxplots, correlation heatmap and pair plots
- 🤖 Linear Regression and Decision Tree Regressor
- 🎯 Hyperparameter tuning using GridSearchCV
- 📏 Evaluated with MAE, MSE, RMSE and R²
- 🧰 **Stack:** Python · Pandas · scikit-learn · Jupyter

[📂 Source Code](https://github.com/SanketManav9620/YESBANK_project)
